# 📘 Recursion in Java – Medium Level

Welcome to the **Recursion in Java – Medium Level** repository!
This repository contains a collection of medium-level recursion problems implemented in Java. It is designed for students, beginners, and coding enthusiasts who want to strengthen their understanding of recursion through practical examples.

---

## 🚀 Topics Covered

This repository includes recursive programs such as:

* 📱 Old Mobile Keypad Combinations
* 🔍 First & Last Occurrence of Character
* 📊 Check if Array is Sorted
* ❌ Move All `x` to End of String
* 🔠 Print All Subsequences
* ✨ Print Unique Subsequences
* 🧹 Remove Duplicates from String
* 🔄 Reverse a String
* 🗼 Tower of Hanoi

---

# 📂 Programs Included

## 1️⃣ Old Mobile Keypad Combination Generator

Generates all possible letter combinations for a numeric string based on the old mobile keypad system.

### Example

Input:

```java
23
```

Output:

```java
dg
dh
di
eg
eh
ei
fg
fh
fi
```

---

## 2️⃣ Find First and Last Occurrence of a Character

Uses recursion to find the first and last occurrence of a given character in a string.

### Example

Input:

```java
"ababaaadadfag"
```

Output:

```java
0
11
```

---

## 3️⃣ Check if Array is Sorted

Checks whether an array is strictly increasing using recursion.

### Example

```java
{1,2,3} -> true
{1,2,2} -> false
{1,4,2} -> false
```

---

## 4️⃣ Move All `x` to the End

Moves all occurrences of character `x` to the end of the string recursively.

### Example

Input:

```java
axbcdxxxe
```

Output:

```java
abcdexxxx
```

---

## 5️⃣ Print All Subsequences of a String

Prints every possible subsequence of a given string.

### Example

Input:

```java
abc
```

Output:

```java
abc
ab
ac
a
bc
b
c
" "
```

---

## 6️⃣ Print Unique Subsequences

Prints only unique subsequences using `HashSet`.

### Example

Input:

```java
aaa
```

Output:

```java
aaa
aa
a
" "
```

---

## 7️⃣ Remove Duplicates from String

Removes duplicate characters recursively.

### Example

Input:

```java
abbccdd
```

Output:

```java
abcd
```

---

## 8️⃣ Reverse a String Using Recursion

Prints the reverse of a string recursively.

### Example

Input:

```java
abcd
```

Output:

```java
dcba
```

---

## 9️⃣ Tower of Hanoi

Classic recursion problem to transfer disks between rods.

### Example

For `n = 3`

Output:

```java
Transfer disk 1 from S to D
Transfer disk 2 from S to H
Transfer disk 1 from D to H
Transfer disk 3 from S to D
Transfer disk 1 from H to S
Transfer disk 2 from H to D
Transfer disk 1 from S to D
```
